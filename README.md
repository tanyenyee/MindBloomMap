# MindBloomMap 🌱

> **A gamified mental wellness and anti-bullying web application designed to help youth and students build emotional resilience.**

MindBloomMap is a non-clinical mental wellness platform designed to assist users in managing their emotional health through three core pillars: **tracking, reflection, and community safety**. Built with a focus on SDG Goal 3 (Good Health and Well-Being), it provides an engaging, nature-inspired environment where users can visualize their emotional trends, access self-care tools, and find a safe, moderated peer-support community.

---

## 📖 About the Project

In today’s fast-paced world, many students carry unspoken emotions and stress without a proper outlet. MindBloomMap bridges the gap in early-intervention digital tools by providing a "first-step," gamified approach to mental wellness. 

**Core Objectives:**
* Provide a secure, accessible tool for youth (ages 16-25) to build emotional awareness.
* Offer an interactive, stress-relief environment before negative emotions escalate.
* Combat school bullying by providing quick-reporting tools and fostering a safe, empathetic community.

---

## ✨ Key Features

### 🌸 Gamified Self-Care (Mood Garden)
* **Mood Logging:** Log daily moods using intuitive emoji-based categories.
* **Virtual Resilience Plant:** Every mood entry and journal reflection contributes to the growth of a personalized virtual plant.
* **Flower House:** A historical overview of your emotional trends, categorized by weekly flowers and detailed journal entries.

### 🤖 AI-Powered Support
* **AI Mood Companion:** Analyzes mood logs to provide an "Overall Vibe" and personalized self-care recommendations.
* **AI Chat Companion:** A conversational virtual friend (powered by Gemini API) that offers interactive check-ins, stress-relief exercises, and empathetic dialogue.

### 🧘 Emotional Toolset
* **Volcano Island:** An interactive, visual tool allowing users to safely "vent" and release intense emotions like anger or frustration through a satisfying eruption animation.
* **Mindful Moments:** A built-in relaxation timer and curated library of calming music for guided meditation and breathing exercises.

### 🛡️ SafeSpace & Anti-Bullying Module
* **SafeSpace Community:** An anonymous, moderated peer-support forum where users can share experiences safely.
* **Quick-Report Tool:** Allows users to report bullying incidents quickly and anonymously.
* **Safety Library:** Educational guidance and resources for bystanders and online safety.

## 🚀 Getting Started

### Prerequisites
* Node.js installed
* npm or yarn
* Firebase project setup
* Gemini API Key

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/MindBloomMap.git](https://github.com/your-username/MindBloomMap.git)
    cd MindBloomMap
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Environment Setup:**
    Create a `.env` file in the root directory and add your backend and API credentials:
    ```env
    REACT_APP_FIREBASE_API_KEY=your_firebase_api_key
    REACT_APP_FIREBASE_AUTH_DOMAIN=your_auth_domain
    REACT_APP_FIREBASE_DATABASE_URL=your_database_url
    REACT_APP_GEMINI_API_KEY=your_gemini_api_key
    ```

4.  **Run the application locally:**
    ```bash
    npm start
    ```
